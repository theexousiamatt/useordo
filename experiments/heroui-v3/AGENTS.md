# Isolated HeroUI v3 proof

This package is a disposable UI compatibility evaluation, not the production app or canonical task backend. Use React19, Tailwind4 and matching HeroUI React/styles3.2.7. No backend/network data calls, environment loading, auth or production operations. Keep root application dependency files unchanged.

Read official component MDX before implementation: https://heroui.com/docs/react/components/<component-slug>.mdx. Official agent guidance: https://github.com/heroui-inc/heroui/blob/v3/skills/heroui-react/SKILL.md. Use package types as the pinned contract when live docs advance. No HeroUIProvider or v2 APIs. Use compound components, onPress, isDisabled/isPending and documented controlled-state props.

Preserve Ordo tokens and installed dnd-kit; one theme on document/portal roots. Do not put raw HSL-channel legacy vars into HeroUI full-color keys. Thin wrappers own visuals/a11y; feature controllers own drafts, mutation guards and task data. Mark synthetic state clearly; do not claim persistence or full-app migration from this proof.
